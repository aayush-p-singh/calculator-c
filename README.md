# Simple Calculator in C

This is a very simple calculator program written in C.  
You enter two numbers and an operator (+, -, *, /) and the program prints the result.

## How it works
The program:
1. Takes input as: number operator number
2. Uses if/else to check the operator
3. Prints the result

Example:
Input:
5 + 3

Output:
8.00

## Concepts used
- Variables
- char input
- if/else conditions
- basic math operators
- printf / scanf
